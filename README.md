# Proposta Comercial — Tempo Recorde

Site estático e responsivo para apresentação da proposta comercial da plataforma de e-commerce escolar.

## Publicar no GitHub

1. Crie um repositório vazio.
2. Envie `index.html`, `vercel.json` e este `README.md` para a raiz do repositório.

## Publicar na Vercel

1. Na Vercel, selecione **Add New > Project**.
2. Importe o repositório do GitHub.
3. Em **Framework Preset**, escolha **Other**.
4. Não informe comando de build.
5. Mantenha o diretório de saída em branco e clique em **Deploy**.

O projeto não usa dependências, variáveis de ambiente ou etapa de compilação.
